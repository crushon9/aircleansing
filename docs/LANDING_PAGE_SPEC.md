# AIR CLEANSING 랜딩페이지 구현 스펙

이 문서는 현재 Git 저장소에 구현된 랜딩페이지의 핵심 구조와 시각 원칙을 기록한다. 세부 픽셀값보다 새 작업에서 지켜야 할 흐름과 행동을 우선한다.

## 1. 제품과 페이지 목적

- AIR CLEANSING은 편백의 우디 향과 베르가못의 시트러스 인상을 담은 일상 공간·패브릭 스프레이다.
- 사이트는 한 제품을 설명하는 정적 랜딩페이지로, 자체 결제·회원·주문 기능을 포함하지 않는다.
- 효능·안전성·피부 관련 문구는 확인된 자료 범위 밖으로 확장하지 않는다.

## 2. 섹션 순서와 역할

순서는 방문자가 문제를 인식하고, 제품을 이해한 뒤, 근거와 사용법을 확인하고, 구매 정보로 이동하는 흐름을 따른다.

1. `hero` — 핵심 태그라인, 제품 이미지, 향·용도·제형 요약
2. `story` — 생활 냄새와 향의 잔향에 대한 문제 제기
3. `gallery` — 사용 장면, 향, 원료, 기술을 시각적으로 요약
4. `product` — 제품 사진, 아로마 프로필, 기본 정보
5. `features` — 공간 케어, 패브릭 배합, 분산의 세 가지 설계 기준
6. `ingredients` — 편백을 중심으로 한 다섯 가지 핵심 원료
7. `technology` — 오일과 워터를 어우러지게 하는 세 단계 분산 설명
8. `usage` — 침구·의류·신발장·욕실 등 생활 공간별 가이드
9. `howto` — 흔들기, 거리를 두고 분사하기, 건조·환기 절차
10. `contact` — 제품 메시지와 구매·문의 준비 상태
11. `footer` — 브랜드와 운영 정보

데스크톱과 모바일 네비게이션은 위 순서와 섹션 `id`를 그대로 따른다.

## 3. 소스 구조

- `app/page.tsx`는 섹션 순서만 보여 주는 조립 진입점이다.
- `app/_components/home/intro-sections.tsx`는 히어로, 브랜드 이야기, 시각 요약, 제품 소개를 담당한다.
- `app/_components/home/detail-sections.tsx`는 설계 기준, 원료, 기술, 공간, 사용법, 마무리와 푸터를 담당한다.
- `app/_components/home/content.ts`는 반복 렌더링하는 카드·단계·원료 데이터를 관리한다.
- `app/_components/home/navigation.tsx`는 플로팅 로고, 데스크톱·모바일 네비게이션, 구매 버튼을 관리한다.
- `app/interactive-effects.tsx`만 클라이언트 컴포넌트이며, 나머지 섹션은 정적 Server Component로 유지한다.

## 4. 시각·인터랙션 원칙

- 향이 번지는 듯한 밝은 아이보리·연두 배경과 진한 초록 기술·마무리 섹션을 교차한다.
- 편백, 숲, 빛, 투명한 단면을 사용하되 글라스 표현은 내용의 가독성을 해치지 않는 수준으로 제한한다.
- 대형 제목은 히어로와 다른 섹션의 최대 크기를 넘지 않도록 하고, 영문 키커와의 간격을 일관되게 유지한다.
- 플로팅 로고와 네비게이션은 배경에 스며드는 얇은 글라스로, 구매 버튼은 더 분명한 입체 글라스로 표현한다.
- 기술·마무리처럼 진한 초록 배경에서는 플로팅 요소의 명도와 대비를 자동 전환한다.
- 섹션 노출, 패럴랙스, 카드 반응, 아로마 바, 분산 입자 애니메이션은 내용의 의미를 보조해야 한다.
- `prefers-reduced-motion: reduce`에서는 핵심 내용이 사라지지 않는 정적 상태를 제공한다.

## 5. 반응형 기준

- 대화면 데스크톱: `1601px` 이상을 기본으로 본다.
- 13인치 노트북: 너비 `901–1600px`, 높이 `1000px` 이하에서 타이포·간격·이미지 크기를 압축한다.
- 태블릿·모바일: `900px` 이하에서 상단 가로 네비게이션과 세로 콘텐츠 흐름으로 전환한다.
- 소형 모바일: `560px` 이하에서 제목·글라스 카드·플로팅 요소를 추가로 축소한다.
- 데스크톱 콘텐츠는 플로팅 좌측 네비게이션을 제외한 가용 영역을 기준으로 정렬한다.

## 6. 완료 조건

- 데스크톱 `1920×1080`, 노트북 `1366×768`, 모바일 `390×844`에서 핵심 섹션을 직접 확인한다.
- 가로 오버플로·제목 잘림·플로팅 요소 겹침이 없어야 한다.
- 데스크톱·모바일 네비게이션의 목록, 순서, 활성 상태가 섹션과 일치해야 한다.
- 유의미한 이미지에 한국어 대체 설명이 있어야 한다.
- `npm run lint`, `npm run build`, `npm test`, `git diff --check`가 통과해야 한다.
