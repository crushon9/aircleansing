# AIR CLEANSING AI 작업 하네스

이 체크리스트는 새 AI 작업이 현재 랜딩페이지의 구조와 시각 톤을 손상하지 않도록 하는 최소 규칙이다.

## 작업 전

- `../AGENTS.md`, `docs/LANDING_PAGE_SPEC.md`, 현재 Git 상태를 확인한다.
- 기존 사용자 변경과 새 요구를 구분하고, 관계없는 변경을 되돌리지 않는다.
- Next.js 코드를 바꾸기 전에 설치된 버전의 `node_modules/next/dist/docs/`를 확인한다.

## 구조·콘텐츠

- `app/page.tsx`는 조립 전용으로 유지하고, 반복 데이터와 섹션 마크업을 다시 집중시키지 않는다.
- 섹션 순서를 바꾸려면 사용자 여정에 대한 근거를 남기고 두 네비게이션 목록도 함께 수정한다.
- 문구는 편백, 가벼운 워터 제형, 패브릭·생활 공간 케어를 중심으로 쓰고, 같은 정보를 여러 섹션에서 반복하지 않는다.
- 근거 없는 탈취·살균·항균·안전성 효능을 추가하지 않는다.

## 시각·인터랙션

- 제목 크기는 히어로와 주요 섹션을 기준으로 하며, 기존 최댓값보다 키우지 않는다.
- 영문 키커와 제목, 제목과 본문, 콘텐츠와 섹션 하단의 간격을 인접 페이지와 비교한다.
- 플로팅 로고·네비·구매 버튼은 콘텐츠를 가리지 않아야 하며, 밝은/진한 배경에서 모두 읽혀야 한다.
- 글라스 효과는 로고·네비에서 배경에 스며들고, 구매 버튼에서는 더 분명하게 보이는 단계를 유지한다.
- 사진 내부 콘텐츠 박스는 둥근 모서리와 충분한 대비를 유지한다.
- 모션은 설명 대상의 의미와 직결되어야 하며, 모션 감소 설정을 존중한다.

## 필수 화면 검증

| 구분 | 뷰포트 | 필수 확인 |
| --- | --- | --- |
| 데스크톱 모니터 | `1920×1080` | 콘텐츠 중앙 정렬, 좌측 플로팅 네비 제외 영역, 구매 버튼 위치 |
| 13인치 노트북 | `1366×768` | 제목·이미지 넘침, 섹션 세로 리듬, 플로팅 요소 겹침 |
| 모바일 | `390×844` | 가로 오버플로, 상단 네비 스크롤, 콘텐츠 순서, 터치 대상 |

세 화면 모두에서 아래를 확인한다.

- 데스크톱·모바일 네비게이션 순서와 활성 상태
- 밝은 섹션과 진한 섹션의 플로팅 요소 대비
- 제목, 본문, 카드, 이미지의 잘림·겹침·불균형한 여백
- 이미지 대체 설명, 키보드 포커스, 최소 색상 대비

4. 세 뷰포트 브라우저 렌더 확인
